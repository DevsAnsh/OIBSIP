# 🌡️ Therma — Temperature Converter

A simple, fast, and beautifully designed temperature converter for Celsius, Fahrenheit, and Kelvin.

## ✨ Features

- Celsius, Fahrenheit, and Kelvin conversion
- Instant and accurate results
- Quick temperature presets
- Absolute zero validation
- One-click copy results
- Responsive design
- Clean and modern UI
- No frameworks or dependencies

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Google Fonts
